# Spec Delta

## Purpose

在本地对导入的视频按可配置的帧间隔执行霍夫圆检测，输出逐帧结果、处理进度和可下载的 CSV，使视频检测与现有图片检测共用同一套参数和判据。

## ADDED Requirements

### Requirement: 视频导入与校验

系统 SHALL 接受 MP4、AVI、MOV 视频文件，读取并返回帧数、FPS、分辨率等元数据；无法解码或格式不支持时 MUST 拒绝请求并说明原因。

#### Scenario: 导入有效视频

- **WHEN** 用户选择一段可解码的 MP4、AVI 或 MOV 视频
- **THEN** 系统返回视频 ID、文件名、帧数、FPS、宽度和高度，并保持视频可供后续处理

#### Scenario: 导入不支持的格式

- **WHEN** 用户提交非 MP4/AVI/MOV 文件
- **THEN** 系统拒绝导入，提示支持的格式，不创建处理任务

#### Scenario: 导入损坏或无法解码的视频

- **WHEN** 用户提交扩展名正确但内容无法解码的视频
- **THEN** 系统返回可读的错误信息，界面保持可用，不产生逐帧结果

#### Scenario: 超出大小限制

- **WHEN** 上传视频超过服务端配置的大小上限
- **THEN** 系统以 4xx 状态拒绝请求，并说明大小限制

### Requirement: 逐帧圆检测

系统 SHALL 按用户指定的帧间隔对视频采样帧执行霍夫圆检测，复用现有 `HoughParams` 的校验与排序规则，并在每条结果中记录帧号和该帧时间戳。

#### Scenario: 处理完成

- **WHEN** 用户以合法参数和帧间隔开始处理一段有效视频
- **THEN** 系统处理从第 0 帧开始的所有采样帧，返回每帧的帧号、时间戳、检出数量及按现有规则排序的圆心和半径

#### Scenario: 某帧未检出圆

- **WHEN** 某个采样帧在当前参数下没有符合的圆
- **THEN** 该帧结果中的检出数量为 0，圆列表为空，处理继续到下一帧

#### Scenario: 参数非法

- **WHEN** 用户提交 dp 不为正数、最大半径小于最小半径且不为 0，或滤波核不是正奇数
- **THEN** 系统拒绝开始处理并指出非法参数，不创建逐帧结果

#### Scenario: 帧间隔非法

- **WHEN** 用户提交小于 1 或不是整数的帧间隔
- **THEN** 系统拒绝开始处理并说明帧间隔必须为正整数

### Requirement: 处理进度与取消

系统 SHALL 为每次视频处理分配任务 ID，并允许查询已处理帧数、总采样帧数、当前状态和错误信息；处理中 MUST 支持取消，取消后不得继续处理后续帧。

#### Scenario: 查询处理进度

- **WHEN** 客户端在任务运行期间查询任务状态
- **THEN** 系统返回 `running`、已处理帧数、总采样帧数和进度比例

#### Scenario: 处理成功结束

- **WHEN** 所有采样帧处理完成
- **THEN** 任务状态变为 `completed`，进度等于总采样帧数，逐帧结果可查询和导出

#### Scenario: 取消处理

- **WHEN** 用户在任务运行期间请求取消
- **THEN** 系统在下一帧边界停止处理，任务状态变为 `cancelled`，已产生的部分结果保留可查

#### Scenario: 处理失败

- **WHEN** 解码或检测过程中出现不可恢复错误
- **THEN** 任务状态变为 `failed`，返回错误信息，不把未完成的帧标记为已处理

### Requirement: 逐帧结果导出

系统 SHALL 允许把已完成的逐帧结果导出为 UTF-8 CSV，至少包含 `frame`、`time_ms`、`count`、`circle_index`、`x`、`y`、`r` 列；无检出的帧 MUST 保留一条 `count=0` 的记录。

#### Scenario: 导出有检出的结果

- **WHEN** 用户对已完成任务请求导出 CSV
- **THEN** 系统返回 CSV，每个采样帧至少一行，检出圆的帧按圆序号展开为多行，文件名包含原视频名

#### Scenario: 导出含未检出帧的结果

- **WHEN** 任务中存在未检出圆的采样帧
- **THEN** CSV 中该帧保留 `frame`、`time_ms`、`count=0` 的记录，`circle_index`、`x`、`y`、`r` 为空

#### Scenario: 任务未完成时导出

- **WHEN** 用户对运行中、已取消或失败的任务请求导出
- **THEN** 系统拒绝导出并说明任务尚未成功完成

### Requirement: 视频验收判据

系统 SHALL 在 README 记录的固定视频样例、固定参数和固定帧间隔下，产出确定的采样帧数量与 CSV 行数，并在至少一帧检出符合半径区间的圆。

#### Scenario: 按固定样例复现验收

- **WHEN** 在仓库根目录运行视频验收命令
- **THEN** 脚本输出采样帧数、CSV 行数、检出帧数、每帧检出圆数量和实际参数，并在判据满足时以退出码 0 结束

#### Scenario: 取消和损坏文件不留下成功结果

- **WHEN** 验收脚本分别执行一次取消和一次损坏视频导入
- **THEN** 取消任务状态为 `cancelled`，损坏视频导入返回错误，两者都不产生标记为 `completed` 的任务

#### Scenario: 样例缺失时明确失败

- **WHEN** 视频样例文件不存在
- **THEN** 验收脚本以非零退出码结束，并提示样例获取方式和期望路径，不跳过视频判据
