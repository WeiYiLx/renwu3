# Spec Delta

## ADDED Requirements

### Requirement: 视频模式

系统 SHALL 在现有界面提供图片与视频模式切换；视频模式接受 MP4、AVI、MOV 文件，并允许设置帧间隔和复用现有检测参数。

#### Scenario: 切换到视频模式

- **WHEN** 用户把模式切换到视频
- **THEN** 界面显示视频文件选择、帧间隔输入和开始处理按钮，并保留当前检测参数

#### Scenario: 选择有效视频

- **WHEN** 用户在视频模式选择一段可解码的视频
- **THEN** 界面显示文件名、帧数、FPS 和分辨率，并启用开始处理按钮

#### Scenario: 选择不支持的视频

- **WHEN** 用户选择非 MP4/AVI/MOV 文件或损坏文件
- **THEN** 界面提示无法读取该视频，保持上一次结果不变，不发起处理任务

#### Scenario: 未选择视频时开始处理

- **WHEN** 用户尚未选择视频就点击开始处理
- **THEN** 界面提示先选择视频，不发起请求

### Requirement: 视频处理进度与结果

系统 SHALL 在视频处理期间显示进度、当前状态和错误信息，并在完成后显示检出汇总、允许预览采样帧标注图和下载 CSV；处理中 MUST 提供取消操作。

#### Scenario: 显示处理进度

- **WHEN** 视频任务正在运行
- **THEN** 界面显示已处理帧数、总采样帧数和进度比例，并周期性刷新状态

#### Scenario: 处理完成

- **WHEN** 任务状态变为 `completed`
- **THEN** 界面显示采样帧数、检出帧数、总检出圆数，并启用 CSV 下载和帧预览

#### Scenario: 取消处理

- **WHEN** 用户在处理期间点击取消
- **THEN** 界面显示任务已取消，停止刷新进度，并保留已完成部分的结果摘要

#### Scenario: 预览采样帧

- **WHEN** 用户在已完成任务中选择一个采样帧
- **THEN** 界面显示该帧的原分辨率标注图、帧号、时间戳和该帧检出数量

#### Scenario: 处理失败

- **WHEN** 任务状态变为 `failed`
- **THEN** 界面显示错误信息，禁用 CSV 下载和帧预览，并保持参数控件可用

#### Scenario: 视频任务运行中切换模式

- **WHEN** 用户在视频任务运行期间切换到图片模式
- **THEN** 界面不丢失运行中任务的状态，重新切回视频模式后仍可查看进度或取消任务
