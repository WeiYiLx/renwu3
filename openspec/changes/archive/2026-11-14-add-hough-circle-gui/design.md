# Design

## Context

仓库当前只有两张样图，没有任何实现代码（见 `proposal.md`）。使用环境是 WSL2 + Python 3.12，已安装 OpenCV 4.6 与 NumPy，但没有 X11 截图工具，也没有 Flask 等 Web 框架。

## Goals / Non-Goals

**Goals**

- 参数调节到出图之间没有手工复制文件的往返，改参数即见结果。
- 验收可在无界面环境下重复执行，并产出与界面一致的标注图。

**Non-Goals**

- 多用户、鉴权、持久化存储。
- 圆形分类（硬币/盘沿）或自动选取参数。
- 视频流与批量目录处理。

## Decisions

### 本地 Web 界面，而非桌面窗口

用标准库 `http.server` 提供页面与 JSON 接口，浏览器作为界面。理由：WSL/远程环境无需 X 服务即可使用，零额外依赖，验收时可用浏览器实际点击并截图。备选方案：Tkinter（需要显示服务器，难在验收环境截图）、PyQt（依赖重）。

### 服务端检测与标注，前端只发参数

前端上传图片一次，之后每次调参只发送图片 ID 与参数，服务端返回标注后的 PNG（data URL）。预览与导出走同一个渲染函数，保证"所见即所得"。备选方案：前端 Canvas 画圆——需要重复实现绘制逻辑，且导出一致性难保证。

### 图片存于内存

以 UUID 索引最近 8 张解码后的图像（LRU），避免每次调参重复上传。进程退出即丢失，符合本地工具的定位。

### 参数集合与默认值

暴露 `dp`、`minDist`、`param1`、`param2`、`minRadius`、`maxRadius`、`blur`。默认 `1.2 / 100 / 100 / 45 / 20 / 0 / 5`，其中 `maxRadius = 0` 表示按图像短边的一半自动取值。半径上下限是区分"外缘"与内部纹理的主要手段。

### 参数校验放在核心层

`dp <= 0`、`maxRadius < minRadius`、滤波核非正奇数等非法组合抛 `ValueError`，HTTP 层映射为 400 JSON；界面显示错误而不清空已有结果。

### 标注样式

圆周用绿色，线宽随图像尺寸缩放（短边 / 300，最小 2 像素），圆心为红色实心点，不写编号文字，避免遮挡实拍图细节。导出 PNG，原分辨率，文件名 `<原图名>-annotated.png`。

### 验收判据脚本化

`scripts/acceptance.py` 直接调用核心层，按 README 中的固定参数处理两张样图，断言检出数量与半径区间，输出圆心、半径和边缘支持度，并写入 `docs/results/`。这样验收结果可由一条命令复现。

| 样图 | dp | minDist | param1 | param2 | minRadius | maxRadius | blur | 期望 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `examples/coins.jpg` | 1.2 | 200 | 100 | 50 | 150 | 210 | 5 | 2 个圆，r 170–190 |
| `examples/cookie-plate.jpg` | 1.2 | 200 | 100 | 40 | 200 | 280 | 5 | 1 个圆，r 235–255 |

## Risks / Trade-offs

- [盘沿对 `param2` 较敏感，取值 40–50 之外会漏检] → README 固定验收参数，脚本使用 40 并在报告中打印实际半径；滑杆调节范围覆盖该区间。
- [大图检测耗时，连续拖动滑杆可能排队] → 前端 250 ms 防抖，服务端按请求并发处理，本地单用户可接受。
- [内存缓存最多 8 张，超大图占用较高] → 限制张数并在替换时释放；不做磁盘缓存。
- ["外缘"语义无法仅靠坐标自动证明] → 组合使用半径区间、圆周边缘支持度与人工查看标注图。

## Migration Plan

全新仓库，无迁移；回滚即删除本次新增目录与文件。
